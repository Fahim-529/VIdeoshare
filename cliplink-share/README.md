# ClipLink — Fast Media & Video Link Shortener

A lightweight, zero-dependency Node.js web application that shortens any URL (YouTube Reels/Shorts, Instagram Reels, Facebook Reels, TikTok videos, or websites), redirects the opener to the main content, and logs the opener's IP address, ISP/mobile carrier, city/country, and phone/device model.

## Quick Start

1. Make sure you have **Node.js (v18+)** installed.
2. Start the server (no `npm install` needed — uses built-in Node.js modules):

```bash
node server.js
```

3. Open your browser at:
```
http://localhost:3000
```
